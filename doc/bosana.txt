Requires Neovim 0.10+ and tmux. There are no Lua dependencies.

=============================================================================
USAGE                                                       *bosana-usage*

Open the editor with :Bosana or: >lua
    require("bosana").open()
<
The buffer shows sessions with their windows indented by four spaces. Each row
has an icon; IDs are concealed text at the start of each row. Use normal linewise
edits, then :w to confirm and apply them. :wq waits for confirmation and applies
successfully before exiting; :q! discards pending edits. :e! discards edits and
loads fresh tmux state.

Default buffer mappings:
    q       Close (refuses unsaved edits).
    CTRL-L  Refresh (refuses unsaved edits).
    g?      Open this help.

=============================================================================
EDITING                                                     *bosana-editing*

An internal row is "/$1 session" or "/@2     window". The ID and following
separator are concealed. Window indentation is four additional spaces.
Icons are inline virtual text, not editable name characters. They follow edits
and undo without entering clipboard contents or tmux names.

Rename by editing the name with cw, C, A, or a substitution. Keep the hidden
prefix intact; cc removes it. IDs travel with linewise cut/paste and undo.

    Edit name                  Rename session/window.
    Remove window row          Delete window.
    Move beneath a session     Transfer window.
    Reorder window rows        Reorder windows, preserving index slots/gaps.
    Remove/empty a session     Delete session; first preserve moved-out windows.
    Reorder session blocks     No effect.

Membership changes honor renumber-windows. Active windows stay selected when
they survive in their original sessions. Window labels use window_name, not
pane_title; rename-window disables automatic-rename as it normally does.

Successful writes refresh state and clear undo history. Undo cannot restore
obsolete IDs after a save. Invalid writes show a short error-styled message and
refresh the buffer from tmux, discarding the invalid edits.

Unsupported: creation, pane editing, linked/shared windows, grouped sessions,
duplicate IDs, control characters in names, empty names,
surrounding whitespace in names, and session names containing '.' or ':'.
Window names may repeat; retained session names must be unique. Blank rows are
ignored. Window indentation must be exactly four spaces, not tabs.

=============================================================================
SAVE CONFIRMATION                                           *bosana-confirmation*

Writes with changes show a synchronous Yes/No prompt listing up to five logical
actions, plus the count of any remaining actions. Temporary renames and links
are represented by their user-visible rename or move. No-op writes do not prompt.

Press y to apply; n or Escape cancels. No is the default. Cancellation leaves the
buffer modified and prevents :wq from exiting. tmux state is checked before and
after confirmation, so changes made while the prompt is open require a refresh.
Set confirm=false to skip confirmation, including in headless automation.

=============================================================================
WINDOW PREVIEW                                              *bosana-preview*

Moving onto a window row shows a read-only, non-focusable floating panel on the
right side of the Bosana view. It captures the visible screen of the window's
active pane with terminal colors and text styles, without scrollback. Output is
clipped to the panel size. Moving between windows updates it; CursorHold and
CursorHoldI refresh output when the cursor pauses, using Neovim's 'updatetime'.

Captures are asynchronous and use the same tmux server and command timeout as
the editor. They do not select windows or panes. Native window IDs keep previews
correct through unsaved renames and moves. Late results from previous rows are
ignored. Capture errors appear inside the panel without changing pending edits.

The panel hides on session headers, blank/unknown rows, when leaving Bosana, or
when the editor is too small. Closing Bosana removes the preview buffer/window;
the floating panel does not prevent :wq or manager-mode exit.
Set preview=false in setup() or open() to disable previews.

=============================================================================
COMMANDS                                                    *bosana-commands*

:Bosana [options]         Open/reuse a view, preserving pending edits.
    --manager            Exclude host and configure its exit lifecycle.
    --exclude-host-session
                         Exclude host without changing its options.
    --socket-name NAME   Use tmux -L NAME.
    --socket-path PATH   Use tmux -S PATH.

:BosanaRefresh[!]         Refresh; bang discards unsaved edits.
:e[!]                    Reload tmux state; bang discards unsaved edits.
:BosanaClose[!]           Close; bang discards unsaved edits.

=============================================================================
CONFIGURATION                                               *bosana-configuration*
>lua
    require("bosana").setup({
      timeout_ms = 5000,
      -- socket_name = "work",
      -- socket_path = "/tmp/work.sock",
      exclude_host_session = false,
      excluded_sessions = {}, -- Native session IDs, e.g. { "$1" }.
      manager = false,
      icons = { session = "▣", window = "▤" },
      confirm = true,
      preview = true,
      keymaps = {
        ["q"] = "close",
        ["<C-l>"] = "refresh",
        ["g?"] = "help",
      },
    })
<
Setup is optional. Socket name/path are mutually exclusive. Without either,
tmux inherits $TMUX or uses the default server. Mapping values are action names,
functions, or false; keymaps=false disables all default mappings.
icons=false disables icons; an empty string hides an individual icon. Icon
highlight groups are BosanaSessionIcon (Title) and BosanaWindowIcon (Special).
confirm=false skips the save prompt. Both require("bosana") and require("Bosana")
return the same public API; lazy.nvim specs can set main="bosana" explicitly.

=============================================================================
LUA API                                                     *bosana-api*
>lua
    local bosana = require("bosana")
    local bufnr, err = bosana.open({ manager = false })
    local ok, err = bosana.save(bufnr)
    local ok, err = bosana.refresh({ bufnr = bufnr, force = false })
    local ok, err = bosana.close({ bufnr = bufnr, force = false })
    local state = bosana.get_state(bufnr)
<
open() accepts per-view configuration overrides. Operations return a result or
nil,error; setup() raises invalid configuration errors. Buffer arguments default
to the current buffer. get_state() returns a copy of the baseline, blocked flag,
buffer number, and last execution report, or nil outside a Bosana buffer.
save() uses the same confirmation as :w unless confirm=false is configured.

=============================================================================
DEDICATED TMUX SESSION                                      *bosana-manager*

Direct interactive startup: >sh
    nvim -c 'Bosana'
<
To open a new window after Neovim startup, use an explicit window name: >
    bind b new-window -n bosana \
        'nvim -c "autocmd VimEnter * ++once lua vim.schedule(function() vim.cmd([[Bosana]]) end)"'
<
-n bosana disables automatic window naming for this window. Otherwise tmux can
rename it after the opening snapshot, making the first save fail with "tmux state
changed since opening the buffer".

Suggested tmux.conf hotkey: >
    bind-key B new-session -A -s bosana -n manager \
        'exec nvim -c "Bosana --manager"'
<
Prefix+B creates/switches to the manager session, or reuses it. --manager resolves
the host by pane/session ID, excludes it from rendering and mutations, sets its
detach-on-destroy=off, and sets its window's remain-on-exit=off. q quits Neovim in
manager mode. Closing the final manager window removes its session; the client
switches to a surviving session, or exits if there are none.

--exclude-host-session only performs exclusion. Host detection requires $TMUX
and $TMUX_PANE and verifies the selected server.

=============================================================================
RECOVERY                                                    *bosana-recovery*

A fresh snapshot is compared to the baseline before a write. External structural
changes, renames, indices, and server restarts require refresh; active-window
selection does not. tmux commands are executed as argument arrays, with names
escaped for tmux format expansion, rather than as shell command strings.

Failed writes show a short error-styled message and automatically refresh the
buffer from tmux. Execution is not transactional; some changes may already have
been applied. Inspect completed commands, the failed command, and the current
operation using: >
    :lua =require('bosana').get_state().last_report
<
After a failed transfer, temporary destination links are removed when the source
still owns the window; cleanup attempts are recorded in the report. Completed
transfers and deletions are not rolled back.

Inspect the refreshed state and reapply remaining changes. If recovery cannot
read tmux, the last known snapshot is restored; writes stay blocked if mutations
may have occurred, until :BosanaRefresh! or :e! succeeds. Recovery failures are
recorded in recovery_error; validation details are recorded in validation.
A failed :wq stays in the editor. Cancelling confirmation retains pending edits.
If an explicit reload fails, pending edits are retained.

=============================================================================
HEALTH CHECKS                                               *bosana-health*

Run :checkhealth bosana (also available as :checkhealth Bosana).

Checks Neovim 0.10+, configuration validity, the tmux executable on PATH and its
version, access to the selected server, unsupported server topology, and host
exclusion when configured. This only reads tmux state; it does not change any
sessions, windows, or options. No running sessions is an informational result.

Bosana always runs tmux from PATH. Before opening and before each tmux command,
it checks that tmux is available and executable. If not, the Lua API and health
check explicitly ask you to install tmux and add it to PATH. Interactive commands
show a short error-styled message.
